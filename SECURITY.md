# Security and responsible publishing

Never commit private keys, passwords, tokens, SSH credentials, complete OPNsense exports, unredacted switch configurations, PCAPs, certificates or production logs. Rotate any exposed credentials. Review usernames, MAC addresses, IP plans and hostnames before publication. Enable GitHub secret scanning if available. Capture only network traffic you are authorized to inspect.

**This repository is public as currently configured on GitHub.** Consider switching it to private until you review infrastructure details.
